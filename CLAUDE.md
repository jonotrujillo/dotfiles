# Dotfiles

See @CHEATSHEET.md for a reference of aliases, functions, and keybindings set up by this repo. Keep it up to date whenever an alias, function, or keybinding is added, changed, or removed.

## Commits

Use `<area>: <lowercase imperative summary>` for the subject, e.g. `zsh: add tool integrations and aliases` or `docs: add README`. The area is the top-level package or folder touched (`git`, `zsh`, `vim`, `ghostty`, `starship`, `brew`, `scripts`, `docs`). Keep the subject short, with no trailing period, and add a body only when the change needs explaining.
